# Discovered Rules — River Crossing Puzzle Web App

## Mandated

- ALWAYS deploy as a static site with no server-side runtime dependency.
- ALWAYS write tests after implementing each component before moving to the next.
- ALWAYS build the walking skeleton (minimal game board page) as the first deliverable.

## Forbidden

- NEVER introduce a backend, database, or server-side component.
- NEVER skip the walking skeleton bolt — it must ship before game logic bolts begin.
